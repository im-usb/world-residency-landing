# World Residency - Single-page website

A responsive, animated landing page built with plain HTML, CSS and vanilla JavaScript. The project photography, amenity imagery, site plan and five apartment layout visuals are sourced from the supplied World Residency brochure and optimized into local WebP assets.

## Run locally

1. Extract the project ZIP.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server, or serve the folder with any static web server.

## Project structure

- `index.html` - semantic page sections, floor-plan tabs and enquiry form
- `style.css` - responsive visual system, transitions and reduced-motion support
- `script.js` - mobile nav, scroll reveals, active navigation, floor-plan tabs, image lightbox and email enquiry handoff
- `assets/images/` - optimized images extracted/cropped from the supplied brochure

## Brochure-derived content included

- Project tower and interiors
- Green view / balcony scene
- Private screening room
- Amenity visuals and the full amenity list
- Site plan
- Unit Layouts 1-5 with brochure-stated areas and configurations where supplied
- Site office address and enquiry email from the brochure

## Before production

- Verify all project copy, specifications, amenity availability, plans and areas with the developer's latest approved material.
- The enquiry form currently opens the visitor's email app addressed to `care@realanchor.com`; connect it to the client's CRM or backend for direct lead capture.
- Add a verified phone/WhatsApp number if the client wants phone-based enquiry buttons.
- The `Download Brochure` CTA has been replaced by an in-page floor-plan CTA; upload a web-optimized brochure PDF and link it if brochure download is required.
- Replace the map search URL if the client provides a confirmed map pin.
